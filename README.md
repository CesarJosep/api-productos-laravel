# API CRUD de Productos - Laravel

API RESTful desarrollada en Laravel para la gestión de productos (Crear, Leer, Actualizar y Eliminar).

## Tecnologías utilizadas
- Laravel (PHP)
- Thunder Client para pruebas de endpoints

## Endpoints disponibles
- `GET /api/productos` - Listar productos
- `GET /api/productos/{id}` - Ver un producto específico
- `POST /api/productos` - Crear un producto
- `PUT /api/productos/{id}` - Actualizar un producto
- `DELETE /api/productos/{id}` - Eliminar un producto

## Cómo ejecutar el proyecto
1. Clonar el repositorio.
2. Ejecutar `composer install`.
3. Configurar el archivo `.env`.
4. Ejecutar `php artisan serve`.
